# IS_Warehouse_Appliances
 Для спільної роботи над інформаційною системою управління складом побутових приладів. Він допомагає команді ефективно організувати процес розробки, зберігати вихідний код, відстежувати зміни та забезпечувати узгодженість у роботі над проєктом. Основна мета – спростити командну взаємодію, централізувати всі матеріали та забезпечити контроль версій.

## Оновлення
Цей файл змінено для тестування коміту в гілці dev.
